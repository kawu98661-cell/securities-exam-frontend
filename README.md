# 证券从业资格考试题库前端

一个简洁、响应式的证券从业资格考试在线练习前端，使用Vue 3、TypeScript和Vite构建。

## 功能

- 按章节练习、综合练习和随机练习
- 单选题即时判分与答案解析
- 答题卡、练习进度和上下题切换
- 成绩统计、正确率和错题回顾
- 自动连接FastAPI题库服务
- 后端不可用时自动启用内置演示题
- 支持电脑和手机浏览

## 本地运行

需要Node.js 22.18或更高版本。

```bash
npm install
npm run dev
```

浏览器访问终端显示的本地地址。

## 连接后端

复制环境变量示例文件：

```bash
cp .env.example .env
```

默认后端地址为：

```text
http://localhost:8001
```

前端使用以下接口：

- `GET /chapters`：获取章节和题目数量
- `GET /questions?chapter=`：获取题目
- `POST /check`：提交答案并判分

未配置或无法连接后端时，项目会自动使用内置演示题，方便直接查看完整交互。

## 构建

```bash
npm run build
```

构建结果位于`dist`目录。

## 说明

本项目用于学习和考试练习演示，不构成投资建议。演示题仅用于展示功能，正式使用前请核对题目内容的准确性和时效性。
