# 证券从业资格考试题库前端

一个开箱即用的在线题库与考试练习前端，使用Vue 3、TypeScript和Vite构建。项目默认以证券从业资格考试为示例，提供章节练习、随机组卷、在线答题、即时判分、答案解析和成绩统计等完整流程。

它不仅可以用于证券考试，也可以作为通用题库前端模板。替换页面名称、题目数据和接口地址后，即可用于职业资格考试、学校练习、企业培训、知识竞赛、课程测验等场景。

项目已经内置演示题，即使暂时没有后端服务，也能直接运行并体验完整交互，适合用于学习、演示和二次开发。

## 项目特点

- 完整练习流程：从选择章节、开始答题到查看成绩和解析
- 多种练习方式：支持章节练习、综合练习和随机练习
- 即时答题反馈：提交后标记正确与错误选项，并展示正确答案和解析
- 清晰的答题进度：包含进度条、答题卡、上下题切换和已答状态
- 成绩结果统计：展示答题数、正确数、错误数和正确率
- 后端自动降级：无法连接接口时自动使用内置演示题，不会出现空白页面
- 响应式界面：兼容电脑、平板和手机，不依赖特定屏幕尺寸
- 正式考试风格：采用白色、深蓝色和浅灰色，界面简洁清晰
- 方便二次开发：题目数据、接口地址、页面标题和视觉样式都可以替换

## 适用场景

- 证券、基金、银行、会计等职业资格考试练习
- 学校课程练习、阶段测验和模拟考试
- 企业内部培训、员工知识考核和安全教育
- 培训机构题库、刷题工具和课程配套练习
- 个人学习项目、Vue前端案例和接口联调演示
- 需要快速搭建单选题练习系统的其他项目

## 使用流程

1. 在首页查看题库数量和章节列表。
2. 选择顺序练习、随机练习或指定章节练习。
3. 阅读题目并选择答案，使用答题卡快速切换题目。
4. 提交答案后查看判分结果、正确答案和题目解析。
5. 完成练习后查看正确率，并重新练习或返回首页。

## 本地运行

需要Node.js 22.18或更高版本。

```bash
npm install
npm run dev
```

浏览器访问终端显示的本地地址。

如果暂时没有后端，直接启动即可。页面会自动加载内置演示题，首页、答题页、解析和结果页均可正常使用。

## 连接后端

复制环境变量示例文件：

```bash
cp .env.example .env
```

默认后端地址为：

```text
http://localhost:8001
```

前端使用以下接口：

| 方法 | 接口 | 用途 |
| --- | --- | --- |
| `GET` | `/chapters` | 获取章节和题目数量 |
| `GET` | `/questions?chapter=` | 获取全部或指定章节题目 |
| `POST` | `/check` | 提交答案并获取判分和解析 |

未配置或无法连接后端时，项目会自动使用内置演示题，方便直接查看完整交互。

## 改成自己的题库

这个项目默认展示证券考试内容，但页面结构并不依赖证券业务。你可以按需要进行以下修改：

- 修改`index.html`中的页面标题，替换成自己的考试或课程名称
- 修改`src/App.vue`中的演示题、章节名称和页面文案
- 通过`.env`中的`VITE_API_BASE`连接自己的后端服务
- 修改`src/styles.css`中的颜色、间距和组件样式，适配自己的品牌
- 按现有数据格式接入其他题库，无需重新设计答题页面

例如，将标题和题目换成“消防安全培训”，再接入对应题库接口，就可以快速得到一套企业培训练习系统。

## 项目结构

```text
src/
├─ App.vue       页面、答题流程和题库数据处理
├─ main.ts       应用入口
└─ styles.css    全局样式和移动端适配
public/
└─ favicon.ico   网站图标
```

第一版专注于练习和判分，不包含登录、收藏、错题本、排行榜和后台管理。需要这些功能时，可以在现有答题流程上继续扩展。

## 构建

```bash
npm run build
```

构建结果位于`dist`目录。

构建后的文件可以部署到常见静态网站服务，也可以由Nginx或现有后端项目直接托管。
